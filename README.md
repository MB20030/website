# Moritz Beyn — personal website

A responsive blue-and-white one-pager. Plain HTML, CSS, and a small progressive-enhancement script; no framework, build step, tracking, or third-party scripts.

Site: **https://mb20030.github.io/website/**

## Editing

- `index.html`: biography, experience, education, highlights, contact, metadata.
- `styles.css`: colors, typography, responsive layout, and print styles.
- `assets/moritz-beyn.png`: supplied portrait in its original colors.
- `script.js`: current year and active navigation. Content works without JavaScript.

Open `index.html` locally or use any static HTTP server. No installation required.

## LinkedIn highlights

The highlight cards are curated summaries, not a live or automatically updated feed. They describe publicly visible updates about the Unibloom internship and HSG podcast. Activity links open the profile's activity page; the podcast links directly to HSG. No API credentials, third-party widget, or invented engagement counts.

Edit the cards in `index.html` when new highlights are available. Individual public post permalinks can replace the activity URL when supplied.
